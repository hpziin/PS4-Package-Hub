

\# Payload GoldHEN



Este é o ponto de partida do payload de diagnóstico.



Compatibilidade desejada:

\- PS4 firmware 13.50

\- GoldHEN 2.4b18.12

\- Carregamento manual pelo BinLoader



Use o template de desenvolvimento:

https://github.com/SirHumza/goldhen-payload-template



Siga as instruções de compilação do template e confirme o suporte

ao firmware 13.50 no SDK.



Atenção:

\- Este payload não tem servidor HTTP.

\- Não baixa PKGs.

\- Não instala pacotes.

\- Não envie o ELF sem confirmar o BinLoader e a porta correta.
